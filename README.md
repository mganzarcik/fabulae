# fabulae

See also [fabulae-showcase](https://github.com/mganzarcik/fabulae-showcase)

To run:

1. clone the repo
2. use the jarWin Gradle task to build a windows-compatible jar (or the other tasks for other platforms).
3. unpack the resulting archive from /lwjgl3/build/distributions/ to a new folder of your choosing.
4. create a modules folder in the /bin/ subfolder of that folder
5. put the showcase module in the modules folder (so that you have /bin/modules/showcase/config.xml)
6. run bin/fabulae
7. have fun
